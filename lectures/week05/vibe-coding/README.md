# Week 5 — Extra session: vibe coding

Building a real tool by talking to an agent. Use the files in this order; each step
starts in a new conversation with the agent in **Planning** mode.

| Step | File | What it gives you |
|---|---|---|
| 0 | [problem-statement.md](problem-statement.md) | The problem statement for the course project, and the template for yours |
| 1 | [prd-prompt.md](prd-prompt.md) | The agent interviews you, then writes `docs/PRD.md` |
| 2 | [design-prompt.md](design-prompt.md) | Approve the PRD, then the agent offers options and writes `docs/DESIGN.md` |
| 3 | [plan-prompt.md](plan-prompt.md) | The MVP split into small, testable tasks: `docs/PLAN.md` |
| 4 | [rules-prompt.md](rules-prompt.md) | The rules every agent must follow in your project: `AGENTS.md` |

[Slides](pes3850-week05-vibe-coding.pptx) — download to open in PowerPoint or Keynote;
GitHub cannot preview a .pptx in the browser.

For your term project: do steps 0 and 1, keep the questions the agent asked you, and
bring both to the project check-in.
