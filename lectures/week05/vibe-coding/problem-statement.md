# Problem statement — Sport data analysis app

*Step 0 of the roadmap. Written by a person, before any AI is involved.*

Sport scientists, coaches and students at a club or department collect data every week: GPS exports, wellness
questionnaires, physical tests, injury records. It arrives as CSV and Excel files. Today, analysing it means either
fighting with spreadsheets or writing Python code, so most of it is never analysed at all.

When someone does build a model, the mistakes that matter most are invisible: a column that leaks the outcome, a
random split that puts the same athlete in training and test data, an impressive accuracy on a rare outcome. The
result is a confident number that nobody can check or reproduce.

**This tool will** let staff upload their files, browse them like a spreadsheet, and run the analyses taught in
PES 3850 by choosing the *question* they want answered, not the algorithm. Every result is shown next to a simple
baseline and comes with warnings when the evaluation is not honest.
